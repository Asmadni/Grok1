## Accessibility Features Implemented (WCAG 2.2)
- 1.4.3 Contrast (AA+): All text ≥4.5:1 (verified #2563eb on white = 5.17:1)
- 2.4.1 Skip link
- 2.4.3 Focus order + visible focus (3px blue outline)
- 2.4.7 Focus Visible
- 2.5.8 Target Size (enhanced)
- 4.1.2 Name, Role, Value (proper labels, ARIA used only when needed)
- Reduced motion support
- Semantic landmarks
